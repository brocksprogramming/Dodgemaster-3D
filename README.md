# Dodgemaster 3D

A high-speed arcade survival game where the player dodges incoming hazards, survives increasingly intense waves, and pushes for a new personal best.

## Overview

Dodgemaster 3D is a fast, replayable reflex challenge built around movement, timing, and risk management. As the arena fills with danger, players weave through obstacles, chain near-misses, and survive as long as possible.

The game is designed to be easy to pick up, difficult to master, and perfect for short, intense play sessions.

## Gameplay

- Dodge incoming projectiles, barriers, and hazard waves
- Survive as long as possible in an ever-tightening arena
- Earn score by staying alive and avoiding collisions
- Compete for higher scores and longer survival runs
- Scale difficulty over time with faster, denser danger patterns

## Features

- 3D arena gameplay with a clear sense of speed and threat
- Responsive controls and smooth player movement
- Increasing difficulty curve for replayability
- Score-based progression and challenge runs
- Minimal but polished arcade presentation
- Quick restart for instant retry loops

## Controls

- Move: WASD / Arrow Keys
- Sprint / Boost: Shift
- Pause: Escape
- Restart after failure: R
- Space: Fire and attack

If you are using a gamepad, the project can also support controller input via the engine’s input system.

## Installation

### Prerequisites

- A modern PC with a supported graphics card
- A supported desktop platform (Windows, macOS, or Linux)
- A compatible game engine/runtime version for the project

### Running the Game

1. Clone the repository.
2. Open the project in your game engine or IDE.
3. Restore dependencies if required.
4. Build or run the project.
5. Begin the run and survive as long as possible.
